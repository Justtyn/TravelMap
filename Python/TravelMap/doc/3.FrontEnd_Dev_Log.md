## 项目结构
- 单模块 Android 工程，`settings.gradle` 仅包含 `app`。
- 根目录：`build.gradle`、`gradle.properties`、`gradle/libs.versions.toml`、`local.properties`（需包含 `sdk.dir`）、`AGENTS.md`、`DEV_LOG.md`、`.idea/`（IDE 配置）、`build/`（本地构建产物）。
- 模块目录：`app/build.gradle`、`proguard-rules.pro`、`app/.gitignore`，编译产物位于 `app/build/outputs/...`。
- 代码主入口：`app/src/main/java/com/justyn/travelmap`
  - Activity：`LoginActivity`、`RegisterActivity`、`MainActivity`、各详情/个人中心 Activity。
  - Fragment：`HomeFragment`、`MallFragment`、`BookingFragment`、`MapFragment`、`MyFragment`、`BaseFeedFragment`。
  - 数据层：`data/local`（`UserPreferences`、`IntroPreferences`、`UserProfile`），`data/remote`（`ApiClient`、`AuthRepository`、`TravelRepository`、`UserCenterRepository`）。
  - UI/工具：`ui/common/ImageLoader`、`ui/feed/FeedAdapter`、`ui/map/MapMarkerRenderer`、`MapPrivacyHelper`、微信封装等。
  - 业务模块：`detail`（景点/商品详情）、`profile`（个人中心二级页与适配器）、`onboarding`（首登引导）、`wechat`/`wxapi`（登录与分享回调）。
- 资源：`app/src/main/res` 下包含布局、矢量图、导航菜单、`values`/`values-night` 配置、地图 Marker 视图等。
- 测试：`app/src/test/java/.../ExampleUnitTest.java`、`app/src/androidTest/java/.../ExampleInstrumentedTest.java`。

## 项目启动说明
1. **环境准备**：Android Studio Iguana+、JDK 17、Android SDK 33+（minSdk 33，compile/target 36）。`local.properties` 中配置好 `sdk.dir`。
2. **后端依赖**：默认 `BuildConfig.API_BASE_URL = http://139.59.227.54:5001`（见 `app/build.gradle`），如需切换到本地/内网，请修改该字段并重新构建。
3. **第三方密钥**：高德地图 key 写在 `AndroidManifest.xml` 的 `com.amap.api.v2.apikey` 元数据；微信 AppId/Secret 定义在 `app/build.gradle` 对应的 `buildConfigField`，若替换签名或包名请同步更新。
4. **构建与运行**：
   - 编译调试 APK：`./gradlew assembleDebug`（输出在 `app/build/outputs/apk/debug/app-debug.apk`），推送设备：`./gradlew installDebug`。
   - 常规检查：`./gradlew lint`、`./gradlew testDebugUnitTest`；如需设备 UI 测试，执行 `./gradlew connectedDebugAndroidTest` 并确保真机/模拟器已连接。
   - IDE 运行：Android Studio 直接选择 Run“app”，首次启动会检查引导与登录态，需要开启网络和定位权限。
5. **数据初始化**：登录成功后会把后端返回的完整 `user` JSON 落地到 SharedPreferences（`travelmap_user_pref`）；若要清空状态，可在“我的”页退出登录或手动清除 App 数据。

## 核心架构与状态管理
- **登录/注册**：`LoginActivity` 与 `RegisterActivity` 通过 `AuthRepository` 调用后端；登录成功即写入 `UserPreferences` 并跳转 `MainActivity`。
- **首登引导**：启动登录页前检查 `IntroPreferences`，未完成则跳转 `OnboardingActivity` 展示 4 页 Banner，完成/跳过后写入 `onboarding_completed` 标记。
- **会话校验**：`MainActivity` 启动及前台恢复时校验本地用户缓存，无用户则强制回到登录页。
- **数据模型**：`UserProfile` 统一封装用户名/昵称/手机号/邮箱/头像 URL 等字段，避免散落解析。

## 首页/商城/预订 Feed
- 三个 Tab 均继承 `BaseFeedFragment`，共享搜索框、Banner、下拉刷新、骨架屏与空态提示，`FeedAdapter` 统一渲染卡片。
- 数据来源：`TravelRepository.fetchScenicFeed()`（首页）、`fetchProductsByTypes()`（商城/预订按类型拆分）。搜索支持键盘 Search/右侧 icon，重复点击 Header 可回顶。
- 交互：点击卡片跳转对应详情页（景点/商品）；列表加载异常会 Toast 提示并展示空态。

## 地图与定位（Plan Tab）
- `MapFragment` 使用高德 3D 地图 + `AMapLocationClient`，调用 `TravelRepository.fetchScenicMapPoints()` 绘制所有景点并叠加当前定位。
- Marker 图标通过 `MapMarkerRenderer` + Glide 缩略图自定义；自动聚焦所有点或单点，支持定位权限申请、缩放、指南针、比例尺。
- 点击 Marker 跳转 `ScenicDetailActivity`，离开页面自动清理 Marker/定位监听。

## 详情页
- **景点详情（ScenicDetailActivity）**：显示标题、城市、地址、经纬度、描述、封面，含骨架屏；地图卡片展示经纬度位置与自定义 Marker；收藏/去过状态实时刷新；支持音频讲解（播放/暂停、拖动、倍速、加载态，离开页面停止播放）。
- **商品详情（ProductDetailActivity）**：展示名称、类型、价格、库存、地址，骨架屏加载；收藏与加入购物车均调用 `UserCenterRepository` 并在按钮旁用 `CircularProgressIndicator` 显示进度。

## 我的中心与交易
- **MyFragment**：头像、用户名/邮箱、常用入口（个人资料、收藏、去过、订单、购物车、关于），骨架屏首次加载；退出登录会清空 `UserPreferences` 并回登录页。
- **收藏/去过**：`FavoritesActivity` 通过 `MaterialButtonToggleGroup` 切换商品/景点收藏；`VisitedActivity` 展示历史去过记录并可跳转景点详情。
- **个人资料**：`UserInfoActivity` 展示/编辑手机号、邮箱，并提供面包屑副标题。
- **购物车**：`CartActivity` 支持数量调整、删除商品、联系信息填写与总价计算；提交后调用 `/api/orders` 创建订单并跳转 `OrderSuccessActivity`，完成后会重新加载购物车。
- **订单列表与详情**：`OrdersActivity` 使用 `FeedAdapter` 渲染订单卡片，点击进入 `OrderDetailActivity`；详情页展示状态、订单号、时间、联系人、总金额、入住离店（如有）以及子项列表，并在地图上标记各商品/景点。
- **关于**：`AboutActivity` 集中展示项目信息与微信分享按钮。

## 技术栈与配置
- 语言/SDK：Java 17，minSdk 33，compile/target 36。
- UI：Material Components、ConstraintLayout、RecyclerView、SwipeRefreshLayout、Shimmer 骨架屏，地图基于高德 3D Map。
- 网络：`ApiClient` 轻量封装 HttpURLConnection，统一 `{code,msg,data}` 响应解析。
- 媒体与加载：Glide 负责图片/Marker 缓存，音频播放使用原生 `MediaPlayer`。
- 第三方：高德地图/定位 SDK，微信登录与分享 SDK（封装在 `wechat` 包）。

## 发布与测试
- 构建：`./gradlew assembleDebug`；安装到设备：`./gradlew installDebug`。
- 质量基线：`./gradlew lint`（静态检查）、`./gradlew testDebugUnitTest`（JVM 单测）。需要设备的 UI 测试：`./gradlew connectedDebugAndroidTest`。
- 打包路径：`app/build/outputs/apk/<variant>/app-<variant>.apk`，调试包默认为 `app-debug.apk`。
- 提交前保持代码格式化（Android Studio Reformat Code）并确保以上命令均通过。

## 隐私与权限
- 权限：`INTERNET`、网络状态、精确/粗略定位；定位仅用于地图与附近展示。
- 本地存储：用户完整 JSON 写入 SharedPreferences（`travelmap_user_pref`），退出登录调用 `UserPreferences.clear()` 清理；未使用 Token。
- 地图隐私：`MapPrivacyHelper` 启动时弹出高德隐私合规提示。

## FAQ
1. **API 文档在哪里？** 详见 https://canulove.me/doc-library 。
2. **拉代码后构建失败？** 确认使用 JDK 17、安装 Android 36 SDK，`local.properties` 填写正确 `sdk.dir`，再执行 `./gradlew assembleDebug`。
3. **需要更换后端地址？** 修改 `app/build.gradle` 中的 `API_BASE_URL` 并重新构建。
4. **地图不显示或无法定位？** 检查是否授予定位权限、设备是否联网，必要时替换高德 key 并重新安装 APK。
5. **如何重新登录？** “我的”页点击“退出登录”即可清空本地缓存；或在系统设置中清除应用数据后重启。
