<a id="公共前提"></a>
## 公共前提
- 默认数据库：`db/TravelMap.db`，若改名请在命令中通过 `--db/--db-path` 显式传入。
- 位置：脚本均位于 `util/` 目录，请从仓库根目录运行，例如 `python util/enrich_descriptions.py ...`。
- 依赖：`requirements.txt` 已包含 Flask/requests/Pillow/dashscope；部分脚本需要额外的 API Key（DeepSeek、DashScope 等）。
- 安全：所有脚本默认跳过已有数据或提供 `--dry-run/--skip-existing`，请先小批量验证再全量执行。

<a id="文案与描述类"></a>
## 文案与描述类

<a id="enrich_descriptions"></a>
### enrich_descriptions.py — DeepSeek 扩写景点/商品描述
- 作用：调用 DeepSeek 将 `scenic` / `product` 的 description 扩写，保持事实不变、风格通顺，并写回数据库。
- 关键参数：`--table scenic|product|all`、`--limit`、`--include-empty`、`--dry-run`、`--show-text`、`--keep-newlines`、`--delay`。
- API 配置：需要 `DEEPSEEK_API_KEY`（脚本中可修改），默认模型 `deepseek-chat`。
- 示例：
  ```bash
  python util/enrich_descriptions.py --table scenic --limit 5 --dry-run --show-text
  python util/enrich_descriptions.py --table product --include-empty --delay 2
  ```
- 细节：自动清理多余空格/风格标签，ASCII 单词之间自动补空格。失败记录会跳过并继续。

<a id="format_description_breaks"></a>
### format_description_breaks.py — 句号后换行
- 作用：遍历 `scenic`/`product` description，将 `。` 替换为 `。\n`，改善前端展示。
- 参数：`--table scenic|product|all`、`--db`、`--dry-run`。
- 示例：`python util/format_description_breaks.py --table product --dry-run`
- 说明：仅更新内容实际变化的记录；`--dry-run` 会显示前 5 条示例差异。

<a id="图片与封面类"></a>
## 图片与封面类

<a id="fill_random_images"></a>
### fill_random_images.py — 占位封面/头像填充
- 作用：从 `image_urls.py` 随机选择 URL，填充空的 `scenic.cover_image`、`product.cover_image`、`user.avatar_url`。
- 使用：`python util/fill_random_images.py`
- 说明：仅处理为空/NULL 的字段，不会覆盖已有图片；可扩展 `image_urls` 列表以丰富素材。

<a id="image_urls_get_url"></a>
### image_urls.py 与 get-url.py — 素材来源
- `image_urls.py`：存放占位图 URL 列表，被 `fill_random_images.py` 引用。
- `get-url.py`：调用 Pexels API 抓取图片 URL 列表的示例脚本，需要在代码内填写 `API_KEY`。生成的 URL 可手动拷入 `image_urls.py`。

<a id="update_cover_prefix"></a>
### update_cover_prefix.py — 批量替换封面域名/编码
- 作用：将封面/音频 URL 前缀从旧域名替换为新域名，并对路径做 URL 编码。
- 参数：`--table` (默认 scenic)、`--column` (默认 cover_image)、`--old-prefix`、`--new-prefix`、`--dry-run`、`--db`。
- 示例：`python util/update_cover_prefix.py --table scenic --old-prefix http://old/ --new-prefix https://new/ --dry-run`
- 说明：仅处理以 `old-prefix` 开头的记录；`--dry-run` 会打印变更计划。

<a id="update_scenic_covers"></a>
### update_scenic_covers.py — 生成景点封面（DashScope 图像）
- 作用：为 `scenic` 生成封面图，保存到 `static/cover/`，并回写 `cover_image`。
- 关键参数：`--mode full|test`、`--scenic-id`、`--limit`、`--skip-existing`、`--overwrite-files`、`--cover-dir`、`--base-url`、`--model`、`--size`、`--style`、`--api-key`。
- 快速示例：
  ```bash
  export ALIYUN_QIANWEN_API_KEY=sk-xxx
  python util/update_scenic_covers.py --mode full --skip-existing --base-url https://your.cdn/cover/
  ```
- 说明：调用 DashScope `wanx` 系列生成写实图；文件名会清理非法字符并可自动加后缀避免覆盖。默认横图 `1280*720`；`--dry-run` 仅打印提示词。

<a id="update_product_covers"></a>
### update_product_covers.py — 生成商品封面（DashScope 图像）
- 作用：逻辑同上，目标表为 `product`，保存到 `static/productCover/`，回写 `product.cover_image`。
- 关键参数：与 scenic 版本一致，新增 `--product-id` 用于单条测试。
- 示例：
  ```bash
  export ALIYUN_QIANWEN_API_KEY=sk-xxx
  python util/update_product_covers.py --mode test --product-id 1 --skip-existing --base-url https://your.cdn/travelmap-coverimage/
  ```
- 说明：会把返回图片转为 JPEG，命名冲突时自动加序号（除非 `--overwrite-files`）。

<a id="音频类"></a>
## 音频类

<a id="generate_scenic_audio"></a>
### generate_scenic_audio.py — 景点描述 TTS
- 作用：读取 `scenic.description`，调用 DashScope Qwen3-TTS 生成语音，保存到 `audio/` 并更新 `audio_url`。
- 关键参数：`--db-path`、`--output-dir`、`--voice`、`--language`、`--model`、`--limit`、`--scenic-id`、`--skip-existing`、`--max-chars`、`--api-base`、`--dry-run`。
- 快速示例：
  ```bash
  export DASHSCOPE_API_KEY=sk-xxx
  python util/generate_scenic_audio.py --skip-existing --output-dir audio --max-chars 600
  ```
- 说明：会清理文本空白并按字符数切分（双字节算 2），多段音频自动拼接；`--dry-run` 只打印计划；`DEFAULT_CDN_PREFIX` 可在脚本中调整为实际 CDN 路径。

<a id="维护提示"></a>
## 维护提示
- 所有生成类脚本建议先用 `--mode test` / `--limit N` 验证 API Key、网络和存储路径。
- 生成的本地文件如需对外访问，请确保与 `--base-url` 或脚本内的 CDN 前缀保持一致并上传到对应 Bucket。
- 对数据库有写操作的脚本都支持 dry-run/skip 开关，跑批前请备份数据库。
