Interactive Demo

UI 概念动态演示

这是一个基于 SVG 和 CSS 动画构建的交互原型，展示了 TravelMap 理想中的流畅体验。

  • 动态路径绘制：实时显示飞行轨迹。
  • 智能卡片切换：到达目的地自动弹出详情。
  • 自适应昼夜效果：完美融合深色模式。

Core Features

完整的本地游解决方案

高德 LBS 服务

集成高德地图 SDK，支持 3D 建筑显示、实时定位、POI 检索与路径规划模拟。

深色模式支持

完美适配系统深色主题，采用 Material Design 推荐的暗色调色板，护眼且省电。

电商交易闭环

从商品浏览、加入购物车到订单提交，完整的模拟支付流程与订单状态管理。

开发历程

从零构建 TravelMap 的迭代开发之路

项目启动 & 基础架构

2025.11.10

确定 MVP 需求范围，搭建 Android 工程，配置 Gradle 依赖，设计 Activity + Fragment 基础容器。

用户认证体系

2025.11.12

完成 LoginActivity 与 RegisterActivity，封装 AuthRepository，实现 Token 本地加密存储与自动登录。

核心功能 & UI 框架

2025.11.15

实现首页 Feed 流，商城列表，引入 Skeleton 骨架屏优化加载体验，完成详情页跳转逻辑。

地图服务接入

2025.11.18

接入高德 3D SDK，实现定位蓝点、自定义 Marker 渲染、景点坐标可视化与隐私合规处理。

电商闭环构建

2025.11.22

完成购物车逻辑，订单提交与状态追踪，实现收藏夹与浏览历史记录功能。

UI 统一与深色适配

2025.11.24

全局应用 Material 3 设计规范，适配深色模式，优化 Safe Area 与交互动效。

v1.0 正式发布

2025.11.25

核心功能验收完毕，Bug 修复，生成发布版 APK，整理开发文档。
